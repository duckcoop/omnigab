# Dependencies live in pyproject.toml, pinned, in one place.
#
# This file stays so that setup.bat's `pip install -r requirements.txt`
# and the SETUP_GUIDE instructions keep working. It installs the project
# itself, which pulls in everything under [project.dependencies].
#
# Editable on purpose. A regular install would copy src/ into
# site-packages, and desktop_app.py would then run that stale copy instead
# of the working tree.
#
# Developers want the test and lint tools too:
#     pip install -e ".[dev]"
#
# Deliberately NOT ".[inference]". llama-cpp-python has no wheels on PyPI,
# so asking for it here would make this file trigger a source build needing
# CMake. setup.bat installs it before this line ever runs, from a prebuilt
# wheel index, via scripts/install_llama_cpp.py.
-e .
